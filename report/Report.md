## Цель работы

Изучить основные типы данных Java, объявление и инициализацию переменных, арифметические и логические операции, объединение строк и форматированный вывод.

## Ход работы

В классе VariablesDemo создан метод main. Объявлены переменные int age, double height, char grade, boolean isStudent и String name. Имя студента — Олег; возраст 20 лет и рост 1.82 м используются как учебные значения.

Для a = 15 и b = 4 выполнены сложение, вычитание, умножение, целочисленное деление и вычисление остатка. Операция 15 / 4 возвращает 3, поскольку оба операнда имеют тип int: дробная часть отбрасывается. Остаток равен 3, так как 15 = 4 × 3 + 3. Для вещественного результата можно записать (double) a / b и получить 3.75.

При x = true и y = false выражение x && y возвращает false, поскольку не оба значения истинны. Выражение x || y возвращает true, поскольку хотя бы одно значение истинно. Оператор ! меняет логическое значение на противоположное. Операторы && и || вычисляют правый операнд только при необходимости.

Оператор + объединяет строки и значения переменных в приветствие. Для вывода роста используется printf с форматом %.2f — два знака после десятичного разделителя; %n добавляет перевод строки. Locale.ROOT задаёт точку в качестве десятичного разделителя.

## Код программы

```java
import java.util.Locale;

/** Демонстрация переменных и операций в Java. */
public class VariablesDemo {
    public static void main(String[] args) {
        // 1. Объявление и инициализация переменных.
        int age = 20;
        double height = 1.82;
        char grade = 'A';
        boolean isStudent = true;
        String name = "Олег";

        System.out.println("1. Переменные разных типов");
        System.out.println("age (int) = " + age);
        System.out.printf(Locale.ROOT, "height (double) = %.2f%n", height);
        System.out.println("grade (char) = " + grade);
        System.out.println("isStudent (boolean) = " + isStudent);
        System.out.println("name (String) = " + name);

        // 2. Арифметические операции с целыми числами.
        int a = 15;
        int b = 4;
        System.out.println("\n2. Арифметические операции (a = 15, b = 4)");
        System.out.println("a + b = " + (a + b));
        System.out.println("a - b = " + (a - b));
        System.out.println("a * b = " + (a * b));
        System.out.println("a / b = " + (a / b));
        System.out.println("a % b = " + (a % b));

        // 3. Логические операции.
        boolean x = true;
        boolean y = false;
        System.out.println("\n3. Логические операции (x = true, y = false)");
        System.out.println("x && y = " + (x && y));
        System.out.println("x || y = " + (x || y));
        System.out.println("!x = " + !x);
        System.out.println("!y = " + !y);

        // 4. Объединение строк.
        System.out.println("\n4. Работа со строками");
        System.out.println("Привет, " + name + "! Тебе " + age + " лет.");
    }
}
```

## Контрольные вопросы

### 1. Какие существуют примитивные типы данных в Java?

В Java восемь примитивных типов: byte (8 бит), short (16 бит), int (32 бита), long (64 бита) — целые числа; float (32 бита), double (64 бита) — числа с плавающей точкой; char — 16-битная кодовая единица UTF-16; boolean — логические значения true и false. String является ссылочным типом, а не примитивным.

### 2. Чем отличается тип int от double?

int хранит 32-битные целые числа от −2 147 483 648 до 2 147 483 647. double хранит 64-битные числа с плавающей точкой, включая дробные значения, с точностью примерно 15–16 значащих десятичных цифр. Многие десятичные дроби представлены в double приближённо. Например, 15 / 4 даёт 3, а 15.0 / 4 даёт 3.75.

### 3. Что означает оператор %?

Оператор % вычисляет остаток от деления. Например, 15 % 4 равно 3. В Java он применим как к целым, так и к вещественным числам. Целочисленный остаток при делении на ноль вызывает ArithmeticException.

### 4. Как объединяются строки в Java?

Строки объединяются оператором + или методом concat(). Если один из операндов + является строкой, другой преобразуется в строковое представление. Например, "Привет, " + name создаёт приветствие. Скобки позволяют сначала выполнить арифметику: "Сумма: " + (a + b).
